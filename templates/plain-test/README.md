# Bản Word bỏ định dạng để thử in

Các file trong thư mục này là bản thử được tạo từ ba mẫu mặc định. Nội dung và khổ A4 được giữ lại; định dạng chữ, định dạng đoạn và viền bảng đã được gỡ để kiểm tra lỗi in.

Print Agent tiếp tục dùng các mẫu gốc trong `templates/theory` và `templates/simulation`. Các bản thử này chỉ dùng để mở trực tiếp bằng Word và gửi in.
